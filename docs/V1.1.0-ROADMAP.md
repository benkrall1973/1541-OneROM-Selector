# v1.1.0 Development Roadmap

This branch prepares the next 1541 OneROM Selector release. The stable v1.0.0 release remains on `main`.

## Compatibility target

- OneROM firmware v0.7.2
- USB plugin v0.3.0
- host-control plugin v0.1.3
- Commodore 1541 device addresses 8-11
- OneROM installed in either physical ROM socket

USB plugin v0.2.1 is the tested v1.0.0 dependency and must not be treated as compatible with OneROM firmware v0.7.2.

## First functional test: T1.1.0-01

The first test intentionally keeps the v1.0.0 screen layout, colors, selection logic, name editing, and SAVE path.

Planned changes:

- Remove the pre-initialization warning screen and its countdown.
- Add `Q = QUIT WITHOUT SAVING` to the main menu.
- Make quit restore the currently active ROM without writing selection or custom-name NV records.
- Consider RETURN as an additional SAVE key after the quit path is proven.
- Change the footer text from `BUILT BY CHATGPT` to `BUILT WITH CHATGPT`.
- Display a unique temporary version number on every test build.

## Correct OneROM label rule

For a multi-chip slot, RBCP returns the label associated with `chips[0]`. Each selectable set must therefore place its single friendly display label on `chips[0]`, regardless of whether that object represents the physical upper or lower 1541 ROM socket.

Label placement as the last JSON member is optional formatting only and has no functional meaning.

## Known observation to investigate

During testing on drive 9, one SAVE after selecting a different image appeared to hang. RUN/STOP-RESTORE was used and the same operation worked on the next attempt. This has not been reproduced consistently and must be tested before release.

## Development policy

- Every test build receives a unique version: `T1.1.0-01`, `T1.1.0-02`, and so on.
- Every test binary must be accompanied by its exact source.
- Do not replace the stable v1.0.0 release artifacts while development is active.
- Preserve the existing layout and colors during the initial compatibility work.
- Optimize size and speed only after SAVE and QUIT behavior are hardware-proven.
- Do not merge this branch into `main` until the release candidate passes the hardware checklist.
