# v1.1.0 Hardware Test Checklist

Record the exact test version, firmware/plugin versions, drive address, physical OneROM socket, and result for every run.

## Required configurations

| Test | Drive | OneROM socket | Required result |
|---|---:|---|---|
| A | 8 | Upper | Detect, menu, quit, save, reboot |
| B | 8 | Lower | Detect, menu, quit, save, reboot |
| C | 9 | Upper or lower | Detect, menu, repeated save |
| D | 10 or 11 | Available setup | Detect and normal completion |

## QUIT without saving

1. Note the active ROM and saved custom names before starting.
2. Run the selector and choose a different ROM.
3. Optionally edit a display name.
4. Press `Q`.
5. Confirm the program exits without hanging.
6. Confirm the 1541 responds immediately to a directory command.
7. Power-cycle the drive.
8. Confirm the original ROM selection and saved names are unchanged.

## SAVE

1. Select a different ROM.
2. Press `S`.
3. Confirm SAVE completes and the drive remains responsive.
4. Power-cycle the drive and confirm the selected ROM persists.
5. Repeat at least five times on device 9 to probe the reported intermittent hang.
6. Test one save with an edited name and one with no name changes.

## Interruption recovery

RUN/STOP-RESTORE is not a normal completion path. If it is used during fault investigation, record:

- The screen/stage where execution stopped.
- Drive LED state.
- Whether the drive answers commands afterward.
- Whether DOS reset or power cycling is required.
- Whether the next identical attempt succeeds.

## Release gate

A release candidate must preserve v1.0.0 selection, edit, restore, SAVE, and socket-detection behavior; complete QUIT without NV changes; remain responsive on devices 8 and 9; and include matching BASIC source, PRG, D64, checksums, and test notes.
